Featured project

AgonCup

Multi-tenant esports tournament platform · team project · ● Public beta

A friend and I built this so Discord servers can run League of Legends tournaments without doing everything by hand. 5 Greek Discord communities use it right now. Our Electron app creates the custom game in each player's League client and starts it by itself. After the game we only accept a winner if at least 6 of the 10 players' clients agree on the result.

  • FastAPI backend: Discord login, WebSockets for live updates, a background worker
  • Postgres row-level security, so one Discord server can never see another's data
  • React admin panel where organisers can sort out disputed results
  • Real users means real bug reports. A lot of my week goes into reproducing and fixing them
