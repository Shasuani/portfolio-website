Featured project

AgonCup

Multi-tenant esports tournament platform · team project · ● Public beta

Used by 5 large Greek Discord communities. Any Discord server can invite the bot and run its own tournaments, with up to 16 teams each and many running in parallel. An Electron desktop client creates and starts custom lobbies automatically through the local League client API, with server-side host failover. A result is accepted only when at least 6 of 10 player reports agree and both teams are represented.

  • FastAPI backend with Discord OAuth2 + JWT, realtime WebSockets and an arq worker
  • PostgreSQL row-level security isolates every server's data, tested in CI
  • React admin console with a dispute / override queue and an audit log
  • Running the beta with real users: triaging bug reports, reproducing issues and shipping fixes
